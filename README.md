# EarthLab

A neobrutalist study desk for **Physical and Geological Structure**.

## Included

- Nine lesson guides based on the attached source PDFs
- Four structured study sections per lesson
- A highlighted terminology desk with lesson-based definitions in every lesson
- One focused quiz per lesson (12 questions each, including situational and college-style questions)
- A lesson dropdown with an all-lessons randomized mixed review mode
- Question and answer-option shuffling on every new attempt
- A score revealer that unlocks the final score and review after completion
- Local progress tracking for completed lessons and best quiz scores
- Credits to Enzo (web builder) and Engr. Karl (PDF reference)
- Source PDF shelf with direct links to each chapter

## Run locally

```bash
npm.cmd install
npm.cmd run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm.cmd run build
```

Progress is stored in the browser under `localStorage`; no account or backend is required.
